## 零、结论

**下一阶段 = Android 收官**，分三段：**A0 出包（今天就能做）→ A1 C3 真机复收 → A2 镜像与发布路径**。

**三条理由（都是硬的）**：

1. **用户优先级原话**是「**时间不多了，得尽快出安卓版**」（§AR「优先级指令」），而**唯一排在它前面的批次 v3 已闭环**（下节有据）。
2. **构建阻塞刚解除**（2026-10-10）：Gradle wrapper 的 `PKIX` 根因 = Watt Toolkit 对 `github.com` 做中间人，而 `services.gradle.org` 307 到 github ⇒ 已换腾讯云镜像，**实测 16 秒下完、Gradle 8.14 启动**，且 `~/.gradle/caches` 已预热 **1.9 GB** ⇒ **出包成本是历史最低**。
3. Android 是首发范围里**唯一还没跑通「装机」**的一块 —— 其余（Windows 桌面、数据层、同步）都已闭环。

## 三、三段的范围与验收

### A0 出包（约半天，**今天就能验证**）

**目标**：拿到**第一个真正能装的 APK**。

1. `flutter build apk --debug` 走通（当前唯一不确定项 = Flutter 引擎产物**首次**下载）。
2. 再出 `--release` —— ⚠️ **签名现状**：`android/app/build.gradle.kts` 的 release 仍用 **debug 签名**（模板默认），**A2 要处理**。
3. 装机冒烟：首启 → 扫码配对 → 开一张单 → 推 → 三态条。

**验收**：手机上装得上、配得上、同步得通。

**为什么排第一**：它是 A1/A2 的**前提**，且**成本最低**（依赖缓存已预热）。

### A1 C3 真机复收（约半天～一天）

1. **③ 标题缩放** —— 需裁定（§CH 的两问：限幅仅窄屏 or 全端；图标是否随缩放）。
2. **①④ 复验**（`KeyboardReveal` + §CJ 的布局批）。
3. 顺手跑一遍 **v3 的真机验收 5 步**（§BD·十六「按箱进货、按瓶卖」+ 整单让价）——
   ⚠️ 我在台账里**没找到你已执行的记录**，若已做过请说一声，我把它补记上。

**验收**：C3 那 4 项全关，且 v3 验收有记录。

### A2 镜像与发布路径收尾（约 2–3 天，**需先裁两件**）

1. **客户端镜像版本门**：`mirror_schema_version`（「重建而非迁移」的落地）—— 现在只有 `rebuildMirror()`，**门没建**。
2. **发布路径**：release 签名（keystore 怎么存 / 不进仓库）、APK vs AAB、随包 LICENSE / 用户手册、装机说明。
3. 与 Windows 的 `packaging/make_release.py` 对齐（要不要一个 `make_android_release`）。

**验收**：出一个**可分发**的签名包 + 一份装机说明。
