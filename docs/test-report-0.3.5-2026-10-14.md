# 0.3.5 预览版本机首批测试报告（脱敏版）

日期：2026-10-14（香港时间）。范围依据 `docs/test-plan-0.3.5-2026-10-14.md`。**本机首批已执行，30 项计划尚未完整完成。** 按用户后续回复“暂时没有，先报告本机测试结果”，本批结束；Windows 发布包与 Android 的实际联调保留待测。

**结论：当前不能给出预览版整体验收通过。** 官方 Android APK 能安装、启动、离线新建商品并在重启后继续选择；但实际发布包仍存在返回确认后不退出、大金额合计裁切及误导性同步说明。源码对照还确认空主库备份、存储日志泄露和四类旧同步残留。上次 10 项残留中，M06 在限定验证内已修复，其余 9 项仍部分处理，不能关闭。

## 1. 对象、环境与方法

- A-035：官网下载的 0.3.5 APK，校验和与发布元数据一致，签名验证通过；安装后应用显示 0.3.5。未自行构建或替换 APK。
- S-035：标签 `0.3.5` 的独立代码快照。精确提交及校验内部留档；没有在旧工作区跑测试后冒充本版结果。
- D-035：全新隔离 Android 模拟器，ARM64、API 37，实际页大小 16 KB。原模拟器未启动或清数据。窄屏阶段设置为 360 逻辑宽度、系统字体 2.0、应用内超大 2.0；显示设置结束时恢复。
- H-01：macOS 测试机，执行 Dart、Flutter 界面及真实回环 HTTP 测试。**这些结果不是 Windows EXE 或 Android 实机的执行结果。**
