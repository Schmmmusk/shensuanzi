## 一、逐项审查

### #34①：往来方流水超大档溢出（下一批做）

- **修法选甲是对的。** 用 `Expanded` 吃满左侧，右侧放金额。这与 #26② 单据列表的修法同构，以后不会再各自漂移。
- **实现纠正**：提案里写「右列金额 (intrinsic)」。在 Flutter 里，`Row` 没有叫 `intrinsic` 的魔法属性。正确的写法是：**右侧不要包 `Expanded`，让它自然占据内容宽度（或者用 `Flexible(fit: FlexFit.loose)`）**，左侧用 `Expanded`。这样在屏幕很宽时，左侧不会把右侧挤出去；屏幕很窄时，左侧截断，右侧永远完整。
- **断言一定要守**：`tester.takeException() == null`，且 `find.textContaining('¥260.00')` 存在。反向灵敏度反向跑一次，非常完美。
- **确认边界**：确实别碰 `_NarrowFlowCard`（窄屏逻辑）和 1.15 的限幅。
