## 新发现漏洞

1. 对于送货类单子，若退货时退全部，之后再点进此类单子时，应当将退货入口关闭，而不是继续显示，误导用户在不知情的情况下继续退款，造成账对不上的损失。
2. 同送货类单子，单号为XS20261012-003的单子中，发生了退货后“已退货”显示-120元，“未退货”仍然显示-120元的现象。当时该单子送货时，未收款，之后发生了退货，便发生了上述现象。
3. 开单页面中，按钮提示的快捷键偶现不可用。手机版没有键盘，也显示了快捷键提示。
