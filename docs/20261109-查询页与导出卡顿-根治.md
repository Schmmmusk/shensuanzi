## 一、问题 1：切页卡约 4 秒

### 取证

代码事实（不需要跑就能确认）：单据页、库存页、往来方页都是

```dart
SingleChildScrollView(
  child: Column(children: [ …头…, Card(child: Column(children: [for (…) _Row(...)]))]),
)
```

`Column(children: [for …])` **一次性 build 全部行**：单据页 200 行 × 每行十几层
widget（排版、状态标签、阴影、字体），在靠 CPU 光栅化的机器上一帧装不下，
于是「点标签 → 4 秒后画面才换」。

> 用户推演的「反序列化不是大头、Widget 构建才是大头」—— **对**。
> 200 行 Map→对象是毫秒级；200 个复杂卡片才是秒级。

### 改法

新增 `lib/src/ui/card_rows_sliver.dart`：`cardRowsSliver()` 用 `SliverList`
（`SliverChildBuilderDelegate`）**只 build 可见的那几行**，卡片外观用
`DecoratedBox`（圆角 12，与 `Card` 默认一致）铺一层底色。

三页统一改成 `CustomScrollView`：

| 页 | 头 | 行 |
|---|---|---|
| 单据页 | `SliverToBoxAdapter`（标题 / 导出 / 搜索 / 三排筛选 / 说明） | `cardRowsSliver`（key `doc-rows`） |
| 库存页 | 同上（含压货榜摘要） | `cardRowsSliver`（key `stock-rows`） |
| 往来方页 | 同上 | `cardRowsSliver`（key `party-rows`） |

**只有一份实现**（`cardRowsSliver`）—— 三页各写一遍必然漂移，这是本仓一直在治的
同构漂移。

## 二、问题 2：导出 / 备份假死

### 取证（26.4 万单，PC/NVMe）

| 段 | 耗时 | 原来跑在哪 |
|---|---|---|
| ① `listDocumentsForExport()` 查库 | **1743 ms** | 主 isolate |
| ② `documentExportTable()` 拼表 | **2033 ms** | 主 isolate |
| ③ `csvBytes()` 拼字节 | **620 ms** | 主 isolate（5a 起在 isolate） |
| ④ 写盘 | 小 | isolate |

⇒ **主线程上 4.4 秒**。而 `setState(() => _busy = true)` 只是标记重建，帧要等这个
同步块跑完才画 —— 所以「导出中…」**永远画不出来**，用户看到的就是假死。

> ⚠️ **一处更正**：写盘（含拼 CSV 字节）**早就**在 isolate 里了（5a，2026-10-24）。
> 用户推演里「拼 CSV + utf8.encode + writeAsBytesSync 全在主 isolate」对
> `ExportService` 已不成立；真正留在主线程的是**查库 + 拼表**（占 3.8 秒）。

备份同理：`wal_checkpoint` 与 **`PRAGMA quick_check`** 都在主线程。
`quick_check` 478 MB 实测 **850 ms**、546 MB 更久 —— 代码注释里早就写着
「正好对上真机那次备份假死」，一直没改。

### 改法

| 位置 | 改了什么 |
|---|---|
| `export.dart` | 新增 `ExportJob` 接口 + `ExportTable.lazy(...)`：**查库 + 拼表 + 拼 CSV + 写盘全在 isolate 里**，主线程只 `await`。isolate 里**按路径新开一条连接**（连接不能跨 isolate，「同一个文件再开一条」可以） |
| `export_tables.dart` | 新增 `DocumentExportJob`（只带路径 + 筛选条件这些可发送的值） |
| `documents_page.dart` | 导出改成传作业，不再在主线程拼表 |
| `backup.dart` | 拷贝 **+ `quick_check` 校验**合并进同一个 isolate；`wal_checkpoint` 仍留主线程（要活连接），但忙碌态已经先画出来了 |
| `paint_first.dart`（新） | `letBusyStatePaint()` = `SchedulerBinding.instance.endOfFrame`：**先画一帧再干重活**。导出按钮与概览的「立即备份」都加了这一句 |

`Db` 新增 `path` 字段（内存库为 `null`）—— 页面要把路径交给 isolate，之前拿不到。

## 四、规格变更（纪律 12 报备）

1. **行不再包在一张 `Card` 里**（改成 `DecoratedBox` + 圆角）。`documents_page_test`
   里那条「只数卡片里的李姐」改用行 sliver 的 key 定位 —— 判据的意图没变。
2. `ExportTable` 多了 `job`；`ExportTable.lazy` 的 `rows` 是空列表（行在 isolate 里）。
   测试用的 `FakeExport` 收到 lazy 表时**就地取一次**，既有断言一行没改。
