## 零、准备（12 分钟，一次做完）

### 0.1 沙箱：与真实数据彻底隔离

外测报告 §T11 用的是「进程级 APPDATA 重定向」。**必须用同一个 PowerShell 窗口**启动软件，
否则重定向不生效：

```powershell
# ① 建沙箱（换掉盘符即可）
$root = 'E:\SSZ-Rerun-065'
New-Item -ItemType Directory -Force -Path "$root\appdata","$root\data" | Out-Null

# ② 解压 v0.6.5 便携包
Expand-Archive -Path 'D:\shensuanzi\shensuanzi\build\dist\神算子-v0.6.5-win64.zip' -DestinationPath "$root\app" -Force

# ③ 进程级重定向（只影响本窗口启动的子进程）
$env:APPDATA = "$root\appdata"

# ④ 启动（必须在同一个窗口里）
Start-Process "$root\app\神算子-v0.6.5\shensuanzi.exe"
```

启动后第一件事：**概览页 →「数据位置」→ 改成 `$root\data`**（向导或设置页的「更改」）。
改完**重启软件**（关掉再 `Start-Process` 一次），确认数据位置已生效。

> ⚠️ **恢复三件套别漏**：`shensuanzi.db` + 删 `-wal` / `-shm`。
> 只覆盖 `.db` 不删 `-wal`，SQLite 会把**旧的未合并日志**套到新文件上 —— 那是数据损坏的经典姿势。

## 附 D：复跑中裁定的口径（2026-10-25 实测，**判据以此为准**）

### D-1 「在店可售」要不要再减在途 ⇒ **要（乙口径）**

实测（C1，`测试大米` 进 5、送货 2 未签收）：

| 量 | 值 | 说明 |
|---|---|---|
| 账面 | 3 | 送货**创建即扣**（`stock_ledger` 落 −2） |
| 在途 | 2 | 未签收送货的数量 |
| 在店可售 | **1** | = 账面 − 在途 |

**用户裁定（2026-10-25）**：「不能卖，因为这批货已经被锁定，要继续卖只能退回来后再卖。」

⇒ **不是重复扣减**，是"已答应客户的货不能再卖"。原稿 B2 写的"账面仍 34 / 可售 31"
是按"签收才扣账面"推的，**与实现不符，已作废**。

⚠️ 遗留一处**描述与实现不一致**（纪律 17，待修）：
`packages/shensuanzi_core/lib/src/dao/query_dao.dart:63` 的注释写
「送货单创建时货已离店（账面已扣），所以在店可售要再减掉在途」——
前半句恰恰是"不该再减"的理由，读起来自相矛盾。应改成
「已发未签的货被这单锁定，签收前不能再卖，故可售 = 账面 − 在途」。
